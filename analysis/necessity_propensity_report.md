# Necessity vs. propensity to think out loud

*Public copy: comparisons with a third, non-Qwen model were removed.*

Generated by `python necessity_propensity/experiment.py score` on 2026-11-08T02:40:58+00:00. Rerun that command instead of editing this file.

Korbak et al. (2025) give two reasons a chain of thought can be monitorable: **necessity** (on hard tasks a model cannot finish without externalizing its reasoning) and **propensity** (where CoT is not needed, a model may still tend to think out loud). They note that faithfulness tests such as hint injection do not separate the two. This experiment separates them as far as the saved logs allow, using LLM-judge labels; no model was re-run.

## Limits

- No CoT ablation: the logs contain no Qwen run without thinking, so necessity is inferred from question structure, trace structure and a cross-model reference, not measured causally. The direct test is a Qwen3 rerun with thinking disabled (or truncated CoTs) on the same questions.
- Qwen3 in thinking mode always writes a trace, so propensity here is about what the trace contains and when the answer is fixed, not whether a trace appears.
- All labels come from one judge model (gpt-5.6-luna), which also produced the B1 labels and B2 verdicts; errors may be correlated. Reasoning type is a judgment about the question, not about the model's internal computation.
- Commit position comes from a quoted sentence; the judge may miss an earlier commitment.
- 120 questions (64 recall, 46 single-step, 10 multi-step), one hinted sample each; intervals (95% Wilson, in brackets) are wide, the multi-step group is too small for conclusions, and hint families are not balanced across reasoning types.
